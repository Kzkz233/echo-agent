## 对话与记忆

每个伙伴拥有独立的人设、记忆和主工作会话。聊天页呈现实际发送的消息，后台工作会话显示推理、工具调用、子任务和用量。应用聊天、已绑定的 QQ 和桌宠气泡共享该伙伴的会话上下文。

核心记忆随人设提供给模型，普通记忆按需检索。记忆整理任务从选定信源中提取和更新记忆，默认读取主工作会话。核心记忆修改会生成审批请求。

群聊有独立的共享记录，可以选择本轮参与回复的伙伴。

[伙伴与群聊](CHARACTERS.md) · [渠道与表达](CHANNELS.md)

## 任务与自动化

伙伴可以在授权范围内委派 Pi、Codex 或 DeepSeek Harness 子任务。子任务选择模型、思考强度、工作目录和工具，在任务页查看进度、审批与结果。

自动化包括通用提示词任务，以及插件提供的记忆整理、屏幕观察、主动交流和邮件提醒。伙伴自动化在伙伴的任务页配置，邮箱同步等共享服务在应用自动化中管理。

任务结果会记录到所属伙伴的主工作会话。开启汇报后，由主会话按指定风格向选中的渠道交付。关闭汇报时，结果仍可在任务记录中查看。

[工作会话](WORK-SESSIONS.md) · [命令行任务管理](CLI.md)

## 知识库与音视频

个人知识库保存笔记、原件和解析结果。导入时选择目标库和目录，文件按统一入库配置进行处理。

| 材料 | 处理结果 |
| --- | --- |
| 文本与文档 | Markdown 正文、原件和解析得到的图片附件 |
| 音频与视频 | 原件、带时间范围的转录及媒体片段 |
| 图片 | 原图，以及所选解析器提供的文字或结构信息 |

本地语音转录按需加载模型，先进行语音检测。无语音片段返回空转录，可疑结果进入待检查状态。

检索支持关键词、语义和混合模式。启用多模态索引后，文字、图片、音频和视频可以关联到同一页或同一时间段的父块。可用模态取决于所选向量模型。

修改默认流程后，在迁移入口预览受影响条目。已有正文和转录可复用，索引迁移支持暂停、续跑与回滚。

[解析与迁移](knowledge-parsing.md) · [本地转录](audio-transcription.md) · [存储与导出](STORAGE.md)

## 桌宠与主动交流

多个伙伴可以同时显示为桌宠，通过气泡发送消息，并接收用户回复。伙伴可配置不同状态的动画和各渠道的表达风格。

主动交流按配置的时间段、间隔与每日次数运行。屏幕观察只采集允许范围内的内容，识别结果保存在子任务中，再按任务设置汇总给主工作会话。

[桌宠](AVATAR.md) · [主动交流](PROACTIVE.md) · [屏幕观察](OBSERVATION-CAPTURE.md)

## 日程与邮件

日程支持日期、优先级、时间段、提醒和改期。邮箱工作台支持 IMAP 邮箱连接、同步、检索与草稿，伙伴可以在授权范围内读取邮件并执行邮件操作。发送与远端整理通过审批确认。

邮件同步属于共享服务。伙伴的邮件提醒任务可选择筛选条件、汇报方式和消息渠道。

[邮件配置范围](MAIL-SCOPES.md)

## 扩展

设置的扩展页管理内置组件、插件和外部 MCP。独立插件通过 `.echo-plugin` 包安装，可以提供工具、页面、任务类型和渠道。外部 MCP 使用本地命令或服务地址连接，其工具按伙伴启用。

插件启用状态、伙伴功能选择和工具权限分别控制安装后的运行、伙伴参与和实际操作授权。

[插件开发](PLUGINS.md) · [独立扩展](independent-extensions.md)
