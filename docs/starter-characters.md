# Aria & Coda

Aria is the everyday companion: conversation, appointments, reading and keeping track of a change of plans. Coda enjoys building small tools, developing extensions and testing ideas. Both can chat about life and use only the capabilities granted to them.

On the welcome screen, choose which companion to talk to and connect a language model. Echo prepares both companions using that connection. Create the shared studio separately if desired. Optional task templates are supplied by enabled plugins. Screen capture, outgoing accounts, terminal access and scheduled tasks require their usual configuration.

| | Aria | Coda |
|---|---|---|
| Appearance | Black bob, ivory streak, jade eyes, apricot cardigan and cocoa skirt | White bob, charcoal streak, red eyes, sea-green hoodie and navy skirt |
| Everyday voice | Notices a detail, makes room for a pause, remembers an agreement | Curious, concise, enjoys sharing how something works |
| Working style | Confirms dates, priorities and the next person who needs a reply | Checks the existing interface, builds a small working example and verifies the result |

Each companion has a portrait, a full-length illustration, a static pixel-art desktop pet and eight chat stickers. A wave, a listening pose or an outstretched hand can accompany a reply in Echo or QQ when stickers are enabled there. Both desktop pets face you from either side of the screen.

App chat, external chat, bubbles and the inbox have separate expression settings. Memory recall, review, proactive contact, observation, mail and delegation use the partner’s own editable guidance. Review starts with the main conversation as its source. An example does not imply access to a mailbox, a screen or a shell.

Existing publisher-supplied companions are upgraded in place. Conversation IDs, memories, permissions and task state survive. Authored defaults and identifiable bundled illustrations can be replaced, while user-edited settings and custom artwork stay with their companion.
