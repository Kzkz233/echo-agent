# Echo Agent 0.18.11

Agent tool history now survives subsequent user turns and application restarts. The shared conversation pipeline commits structured Pi actions and tool results independently of the bounded diagnostic log, including plugin and external MCP operations. Main conversations, delegated workers and agent-based automation use the same implementation.

Automatic compaction preserves recent tool-call/result batches and persists in-run checkpoints for later restoration. Interrupted calls retain an unknown outcome without repeating side effects. Selecting a new main language model restores the existing session rather than attempting a full lifetime-history import.

Migration adds ordered references without rewriting existing messages, character settings, permissions, memory or task configuration. Chat rendering and Review source selection remain independent of raw tool traces. Transient tool media is explicitly omitted from durable history. External worker hosts retain their native session boundaries.
