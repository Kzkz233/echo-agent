## Echo Agent 0.17.5

- Add concise model-visible message headers with explicit `time`, `sender`, and optional `channel` / `task` fields. Keep the original chat text unchanged.
- Supply a local-time snapshot for each conversation turn using the application clock. Preserve original message times through queues and history replay.
- Carry channel identities and automation sources through the shared conversation, including delegated task results.
- Expose a typed, lifecycle-managed message-source extension point for plugins. Saved source descriptions survive plugin unloading.
- Use the shared renderer in API, Pi, Codex Worker and DSH Worker transports, with context budget accounting that includes headers.
- Remove the conversation title from desktop-pet reply bubbles and tighten text/image spacing.

Install the Windows x64 setup package to update an existing installation. Application data, installed extensions and external MCP configuration are stored separately from application files.
