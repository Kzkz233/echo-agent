角色的「角色功能」页现在集中显示插件工具。你可以分别给主会话和子任务授权，查看插件还缺哪些配置，并直接打开对应的设置。

## 从 0.21.11 升级

- 新增 Zotero 插件。连接本机文献库后，可以检索题录、管理分组和笔记，并将附件关联到已有知识条目。
- 新增浏览器操作和 Windows 桌面操作插件。浏览器在独立会话中访问已授权的网站，桌面工具可读取已授权前台应用的控件并执行交互。两者分别支持读取和操作授权。
- 聊天支持收发文件。用户发出的消息会立即显示，任务交付的附件可从对话中打开。
- 备份支持跨设备迁移角色、任务配置、知识库、索引和已安装扩展。迁移后可在新设备上启用扩展并配置本机凭据。
- 任务详情将执行结果、主会话接棒和渠道回执放在一起。角色编辑只保存改动的字段，删除任务需明确操作。

覆盖安装会保留现有配置和角色权限。浏览器操作和桌面操作都需要先配置访问范围，再为角色授权。
