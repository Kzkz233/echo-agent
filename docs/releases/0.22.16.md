Aria 和 Coda 成为 Echo 的两位初始伙伴。这个版本也改进了桌宠显示、定时任务的汇报，以及长对话遇到空摘要时的恢复。

## 新增

- Aria 偏向日常陪伴，Coda 偏向开发协作。两位伙伴各有独立的人设、头像、聊天表情和静态像素桌宠。

## 改进

- 在任务配置中直接设置整理时间。补跑和续跑沿用选定的收件人，汇报时检查渠道是否可用。
- 修正在不同屏幕缩放比例下重启桌宠时，显示大小发生变化的问题。
- 模型完成压缩请求却只返回空白正文时，Echo 会保留原始历史，请模型重新写一次摘要。有效的短摘要可以直接使用。网络重试和这一次纠正共用同一个重试预算。

## 升级说明

可通过应用内更新或安装程序覆盖升级。升级沿用本机的伙伴、知识库、权限和任务配置。
