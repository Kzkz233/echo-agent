## Echo Agent 0.17.6

- Serialize native settings-window creation so repeated requests share one window. Prevent duplicate windows from leaving stale native state after closing.
- Restore a minimized settings window before bringing it forward.
- Show a visible error if the settings window cannot be opened.
- Add isolated desktop regression coverage for concurrent opening, close/reopen cycles, page changes, sidebar navigation and failure reporting.

Install the Windows x64 setup package to update an existing installation. Application data, installed extensions and external MCP configuration stay in their separate data directory.
