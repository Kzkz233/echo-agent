记忆整理、定时任务和日程提醒现在可以分别设置错过执行时间后的处理方式。日程提醒支持角色的聊天渠道，模型连接中断时也有更多自动重试机会。

## 改进

- 在定时任务里选择「恢复后补一次」「仍有效时补一次」或「跳过本次」。连续错过多个周期时，补跑会合并为一次。任务详情可查看原定时间、实际处理时间和处理结果。
- 每个启用日程功能的角色都有一项「日程提醒」任务。在角色配置的「自动化任务」中选择提醒渠道，单条日程也可以覆盖这个选择。提醒会记入角色主工作会话，清空渠道后只保留这条记录。发送提醒本身无需调用模型。
- Pi 和直连 API 遇到可恢复的网络或上游服务故障时，每个模型请求步骤最多额外重试五次。已经执行的工具保留原结果，已经开始输出的回复保留现场。

## 修复

- 修复部分文档解析器读取已归档原件时误用 16 MB 上限的问题。MinerU 现在按其声明的文件大小上限读取 PDF。

## 升级说明

现有角色、任务、权限和知识库可沿用。记忆整理默认在恢复后补一次，合并处理尚未整理的材料。普通角色定时任务默认允许延迟 60 分钟，日程提醒默认只在日程仍有效时补发。需要在手机接收提醒时，在对应角色的「日程提醒」里勾选已绑定的 QQ 渠道。
