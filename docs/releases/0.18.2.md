# Echo Agent 0.18.2

- Return completed and remaining channel targets in reply-tool receipts. Selected destinations come from the current request or task, independently of the inbound channel.
- Attribute worker memory receipts to their execution and include confirmed ordinary-memory changes in interruption reports. Historical traces are checked against the durable mutation journal; task interruption does not imply that no writes occurred.
- Preserve character-level handoff instructions, task reporting settings and existing delivery receipts. Completed deliveries are not automatically replayed.

Includes the 0.18.1 application/character automation boundary and interrupted-review reporting fixes.
