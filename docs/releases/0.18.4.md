# 0.18.4

Desktop avatars face toward the center of the work area when resting along its
bottom edge. Moving right to dock no longer leaves the avatar facing outward
after arrival. Walking and dragging keep their existing direction behavior.

Message bubbles omit conversation-name headers and use compact text/image padding.
The reply editor also omits routing-name headers.

Native renderer libraries can now extend the shared avatar host through a
versioned ABI. Optional body renderers reuse the base windows, bubbles, input,
movement and receipts instead of shipping a second implementation of those parts.

Native avatar diagnostics include the current facing direction. Existing role,
animation, observation, task and permission settings remain unchanged.
