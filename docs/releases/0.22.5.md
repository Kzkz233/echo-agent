这次更新简化了首次聊天和角色配置，并把文献浏览、任务诊断和续跑放到了对应的工作页面。

## 从 0.22.1 升级

- 首次打开 Echo 时，可选择 Hina 或 Miyu，在同一页连接模型并开始聊天。双人工作室可单独创建。
- 模型服务按用途展示。新安装自带可离线使用的中文 BGE 文本索引模型，也可通过本机 Ollama 下载并使用 Qwen3 4B 聊天。
- 角色、任务和插件设置优先显示常用选项。可搜索具体的角色设置，直接定位到折叠的字段。角色可查询自己的能力，并在已有权限范围内更新偏好和任务。
- 知识库可切换资料来源。启用 Zotero 文献连接器后，可按分组浏览和搜索题录，查看短评、评分、附件及 Echo 索引状态。
- 失败任务的详情页提供诊断信息。支持断点的任务可从已保存的进度续跑。
- 常规设置新增模型网络代理和 Windows 登录后启动选项。

已有安装会沿用当前角色、权限、任务配置和索引模型。新安装的知识库默认使用混合检索，尚未建立向量的笔记也可以按关键词找到。[更新与恢复](https://github.com/Kzkz233/echo-agent/blob/v0.22.5/docs/UPDATES.md)
