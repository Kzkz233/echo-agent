# Echo Agent 0.18.9

- Fix compatible Responses gateway failures caused by empty response-only annotation metadata in assistant history, for both Pi and direct model tasks.
- Require native tool selection for Pi channel deliveries on Chat Completions and Responses, starting with the first request. Work tools remain available; ordinary text is never automatically forwarded or regenerated.
- Preserve intentional quiet outcomes with an explicit silence tool, available only when the caller permits silence and no reply has started.
- Clarify that program-added message headers are provenance, not content to imitate in a reply.
- Preserve existing models, thinking settings, prompts, permissions, tasks, extensions and user data. Retain borderless capture and overlay exclusion.

Protocol references: [DeepSeek Responses compatibility](https://api-docs.deepseek.com/guides/responses_api/), [Anthropic tool choice restrictions](https://platform.claude.com/docs/en/agents-and-tools/tool-use/define-tools).
