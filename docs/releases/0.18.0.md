# Echo Agent 0.18.0

- Unify Agent automation and delegated work under character-owned work sessions, with execution history and links to the source task.
- Add configurable child-session context injection. Persona and core memory are enabled by default; automatic recall is optional.
- Enable context compaction for Pi workers, automated conversation inputs and ongoing tool loops. Per-call output limits inherit the selected model unless overridden.
- Run new memory reviews with versioned memory tools and core-memory approvals, instead of a detached, tool-disabled JSON loop.
- Preserve task results in the parent conversation and optionally let the character report through selected channels. Freeze destinations and deduplicate result handoffs.
- Add general prompt automation and character-scoped task-management tools.

Existing character data, prompts, permissions, external MCP servers and independently installed extensions are retained. Interrupted legacy Review batches remain explicitly resumable; later scheduled batches can collect new material independently.
