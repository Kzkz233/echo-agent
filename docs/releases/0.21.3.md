修复模型配置保存与参数继承，取消长任务的隐式执行时限。

## 改进

- 新建委派任务、通用自动化和记忆整理默认不限总时长；执行时限设为 `0` 表示不限时。
- 取消任务时限最多两小时的限制，保留明确配置的截止时间和手动取消。
- 模型设置在保存按钮旁显示结果；思考能力读取失败时显示错误，已有缓存时保留上次读取的选项。
- 新模型的单次输出默认自动采用模型声明的容量，未知时使用通用默认值；手动上限和输入字符预算移入高级设置，现有手动配置保留。
- 取消单次输出参数的固定 128K 配置上限，实际请求仍遵循模型容量与可用上下文。

## 修复

- Pi、Codex 和 DSH 持续推进的任务不再被隐藏的三十分钟上限中断。
- 切换模型或服务后，已放弃的草稿不再反复触发未保存提示。
- API 模型的上下文容量和输出参数格式可在已有运行待核对时保存，从下次请求生效。
- 审批代审、检索辅助和上下文压缩使用统一的生成参数继承规则，移除额外写死的思考开关与输出额度。
- 未声明模型 token 容量时，不再用输入字符预算误限输出长度；压缩失败保留原始历史。
- 修正旧 API 连接被显示为“外部执行器”的分类。

## 升级说明

现有角色、任务、权限、模型配置和独立扩展继续保留。已保存的任务时限仍然有效，需要不限时可将其改为 `0`。模型单次请求的超时与输出上限继续生效。
