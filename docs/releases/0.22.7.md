文献库现在可以在同一分组内切换题录和正文，直接检索、阅读已存入 Echo 的知识页。

## 改进

- 在「知识库 → 文献库」选择分组，切到「正文」即可浏览已入库的文章。在「高级搜索」里可选关键词、语义或混合检索，并从命中位置开始阅读。
- 题录列表区分无附件、仅含网页链接和有 PDF 待入库的文献。展开一条题录，可以分别查看主文、补充材料等附件的入库和索引状态。
- 同步目录后，关闭 Zotero 仍可浏览已缓存的题录、分组和 Echo 知识页。重新同步会更新题录和分组，已移出 Zotero 的文献仍可查看保留的知识页。

## 升级说明

「Zotero 文献连接器」随安装包提供，新安装默认关闭。需要时在「设置 → 扩展」启用，连接本机 Zotero 并同步目录。导入正文时，在对应附件旁选择「导入或复用 PDF」。新 PDF 默认进入 Zotero 文献库，已匹配的原件沿用原知识页和索引，无需重新解析或向量化。
