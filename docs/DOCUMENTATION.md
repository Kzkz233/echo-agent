# 文档规范

[文档](README.md) / 项目维护

## 内容归属

| 位置 | 职责 |
| --- | --- |
| 根 README | 产品定位、实际界面、核心能力、安装入口和文档入口 |
| docs/README.md | 文档导航 |
| 使用指南 | 完成具体操作所需的步骤、条件与结果 |
| 架构与接口文档 | 模块职责、数据结构、生命周期、接口和兼容规则 |
| docs/releases | 各版用户可见的变更和升级说明 |
| 历史记录 | 某次实现、调查或验收的事实与范围 |

## 写作

- 一篇文档围绕一个主题，标题说明内容，开头说明用途。
- 优先使用短段落、操作步骤和用于比较的表格。
- 功能介绍描述已支持的行为。条件和限制放在对应配置或操作旁。
- 界面名称与应用保持一致，代码标识保留原文。
- 同一事实由一处文档完整说明，其他页面链接过去。
- 结果与承诺应有代码、测试或实际验收依据。历史测试数量属于对应版本的记录。

用户入口文档使用中文。接口参考可使用英文，新增或修改页面遵循所在文档的语言。

## 截图与示例

截图取自隔离环境，使用公开示例伙伴和虚构内容。优先展示完整操作场景，保持实际界面比例。首页图片兼顾 GitHub 的深色与浅色主题，并提供替代文本。

新增媒体保留生成来源与素材许可，通过发布范围检查后纳入仓库。示例中的路径、账号和数据使用通用占位内容。

## 验证

检查相对链接、页内锚点、图片路径和 Markdown 渲染。命令与当前入口核对，用户操作与当前界面名称核对。修改产品行为时，同时更新对应使用指南和接口文档。
