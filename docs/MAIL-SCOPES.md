# 邮件与角色

邮箱、凭据和同步任务由应用管理。同一邮箱同步一次，角色通过「配置角色 → 工具与委派 → 可访问邮箱」取得访问范围。旧账户的关联角色继续作为默认授权，保存角色的邮箱选择后使用明确的授权清单。新账户在授权前只供应用工作台使用。

在「设置 → 扩展 → 邮箱工作台」按顺序设置邮件提醒规则。第一条命中的规则决定提醒或不提醒，未命中默认不提醒。条件支持主题文字、精确发件人、发件人域名和稿件编号。例外发件人可以跳过对应规则，继续匹配后面的规则。规则在同步新增邮件时评估，邮件正文仍按需读取。

在角色任务中选择「新邮件触发提醒」，指定已授权的邮箱、筛选方式、提醒时段、冷却时间和输出位置。使用应用规则时，任务可再加发件人或主题条件。原有任务专用筛选仍可使用。创建或启用任务从当前收件游标开始，首次同步和历史补录不会补发通知。示例角色带有关闭的提醒任务，授权并选择邮箱后即可启用。

每个 Review 任务可以选择已授权邮箱作为材料流。角色工具对查看邮件、编辑草稿和申请邮件操作执行同一份邮箱授权检查。邮件发送和远程移动仍经过应用审批。
