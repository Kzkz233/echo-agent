# 快速开始

[文档](README.md) / 快速开始

## 安装

下载最新 Release 中的 `Echo-Agent_<版本>_x64-setup.exe`，运行安装程序。当前安装包面向 Windows x64，包含桌面应用、后台运行时和命令行工具。WebView2 缺失时，安装程序会联网补齐。

[下载 Windows 安装包](https://github.com/Kzkz233/echo-agent/releases/latest)

## 连接模型

1. 打开 **设置 → 模型服务**，添加服务。
2. 选择对应接口，填写服务地址和 API Key，或配置已有的本地模型服务。
3. 测试连接，获取模型列表，保存要使用的模型。

主聊天需要支持工具调用的语言模型。屏幕观察需要支持图像输入的模型，可以单独指定。在线服务的费用由相应服务商收取。

同一个服务可以配置多个模型。角色选择主模型，任务可以继承该选择或指定自己的模型。输出上限和思考强度随模型能力配置。

[模型服务](INFERENCE.md)

## 创建角色

在侧栏的 **角色** 旁点击加号，选择创建方式。

- **从示例开始** 提供 Hina、Miyu 和双人工作室，包含人设、表达风格与桌宠素材。
- **新建角色** 可自行编写人设，选择模型、插件和权限。
- **导入角色包** 可载入已有角色设计，并配置本机模型与渠道。

指定语言模型并保存后，打开角色的 **聊天** 页面。执行过程、工具调用与上下文用量位于 **后台工作会话**。

[角色配置](CHARACTERS.md)

## 配置功能

| 要做的事 | 入口与设置 |
| --- | --- |
| 让角色读写文件 | 在角色配置中设置工作目录和文件权限 |
| 使用外部工具 | 在设置的扩展页添加外部 MCP，再为角色启用和授权 |
| 开启桌宠 | 在角色配置中启用桌宠并选择素材 |
| 定时整理记忆 | 在角色任务中配置记忆整理的信源、周期和汇报渠道 |
| 导入资料 | 打开知识库，选择目标目录后导入原件 |
| 观察屏幕 | 配置视觉模型、允许观察的网站或应用，并启用观察任务 |

## 更新与备份

在 **设置 → 运行维护 → 版本与更新** 检查更新。应用会核对桌面、前端和后端构建，等待运行中的工作到达安全点后重启。

数据目录与应用安装目录分别管理。备份包含应用记录和注册的知识库，恢复时使用新的空数据目录。凭据需要另行配置。
